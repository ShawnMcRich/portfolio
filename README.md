# Shahin Ghanizadeh Portfolio

Bilingual English/Persian portfolio for Shahin Ghanizadeh, focused on technical product management, applied AI, frontend leadership, and evidence-based product case studies.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm run lint
npm test
```

The production site is configured for OpenAI Sites through `.openai/hosting.json`.
